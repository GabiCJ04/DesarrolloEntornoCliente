Por qué comparten motor

Chrome, Edge y Opera comparten Chromium, un proyecto de código abierto.
Reutilizar esa base permite aprovechar trabajo común y dedicar recursos a otras funciones.
En sus versiones de escritorio utilizan Blink para representar HTML y CSS, y V8 para JavaScript.
Firefox queda fuera de Chromium y emplea Gecko y SpiderMonkey.
Safari también utiliza una base distinta, con WebKit y JavaScriptCore.
Compartir motor facilita la compatibilidad, pero las versiones y las funciones disponibles pueden variar.
Por eso, comprobar una web en un solo navegador no garantiza que funcione igual en los demás.

Compatibilidad de CSS :has()

El selector article:has(img) selecciona los artículos que contienen una imagen.

Chrome y Edge lo admiten desde la versión 105, Safari desde la 15.4 y Firefox desde la 121. En Firefox 120 está desactivado por defecto y en Safari 15.3 no está soportado: una regla que lo use no se aplica en esos casos.

Es una diferencia entre versiones: las versiones actuales de estos navegadores ya lo admiten.
